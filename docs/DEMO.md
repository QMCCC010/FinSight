# 答辩演示指南

## 演示前

1. 提前启动Docker Desktop并执行`.\scripts\start.ps1`。
2. 至少运行一次在线同步，形成本地快照和模型缓存。
3. 检查`http://localhost:8000/health`和`http://localhost:5001/health`。
4. 打开前端并确认两类账号均可登录。
5. 若答辩网络不可用，将`COLLECTION_MODE`改为`SNAPSHOT`后重启服务。

## 十分钟演示脚本

1. 用一句话介绍：系统自动汇聚四类金融信息，并生成有来源的研究辅助结果。
2. 管理员登录，展示四个数据源和定时策略。
3. 点击“全部立即同步”，观察任务从等待、采集、解析到索引完成。
4. 进入比亚迪详情页，解释行情背景、资料构成、预测/评级图和去重后的事件聚类。
5. 生成研报对比，指出评级、目标价、预测和风险差异。
6. 提问“比亚迪最近有哪些主要风险？”，展开原文引用。
7. 提问“分析贵州茅台最近的机构观点”，展示按需建立知识库和自动续答。
8. 在工作台生成研究简报并下载Markdown。
9. 用研究用户登录，验证管理后台不可见。
10. 强调系统不执行交易，结论均需结合来源和数据截止时间理解。

可追加演示：“这个系统能做什么”会直接回答；随后询问公司并追问“它的预测呢”，展示问题路由和多轮公司上下文。

## 预期异常及说明

- 在线网站不可访问：系统回放本地快照，并在来源标题中明确标记。
- 模型接口不可用：系统使用规则抽取及证据拼接，不编造模型结果。
- 某一来源失败：回答状态为`PARTIAL`并列出缺失来源。
- 新公司没有公开研报：保留已获取公告和新闻，明确说明无法形成有效研报对比。
